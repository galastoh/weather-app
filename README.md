# MINI WEATHER APP
This is a Python mini weather app that fetches current weather using the OpenWeatherMap API.

## FEATURES
- Get current temperature, humidity, and weather description.
- Input city name and get results.
- Clean and organized output.

 ## HOW TO RUN
1. Install Python and 'requests' module.
2. Put your OpenWeatherMap API key in the config.py.
3. Run app.py (or whatever your main file is named). 

NOTE: This was for my training purpose.
